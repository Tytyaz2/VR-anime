# ANIM ATTACK VR

## Objectif général
Anim Attack c'est une application VR permettant d'exécuter des techniques d'animés (Kikoha, etc.) via la détection des gestes des mains. L'utilisateur interagit dans un environnement virtuel dynamique où les techniques sont déclenchées par des mouvements spécifiques.

## Matériel nécessaire 
Casques VR compatibles avec la détection des gestes via caméra intégrée, tels que Oculus Quest ou HTC Vive. Détection par caméra ou suivi de mouvement avec les manettes VR suivre les mouvements des mains et déclencher des actions dans l'application.

## Technologies utilisées
- Unity 6
- Script C#

## Actions
- Attaques détectées par les mouvements de mains : Makankosappo, Kikoha, et Finger Beam.
